# Medit USA LTD

A static marketing landing page for Medit USA LTD.

Serve the folder with any static web server, or open `index.html` in a browser.

## Placeholders to fill in before going live

- Contact email is set to `info@meditusa.com` and is labeled as a placeholder on the page. Replace it in `index.html` (the mailto form action and the contact note) and in `js/main.js` (`CONTACT_EMAIL`).
- A phone number and postal address are not included. Add them in the contact section when you have them.
